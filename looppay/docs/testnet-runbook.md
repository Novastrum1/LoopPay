# Testnet release runbook

No QIE deployment or verification is claimed. Use a fresh database and a separate test-only encrypted Foundry keystore. Never send keys, passwords, recovery words or real funds to a collaborator. Only a human operates the keystore prompt. Commands below run from looppay/.

1. **Configure:** copy `config/qie.testnet.example.env` to ignored `.env.local`. Confirm chain 1983, RPC and explorer against [official network docs](https://docs.qie.digital/getting-started-with-qie-blockchain/4.-access-mainnet-or-testnet). Supply public values only. Keep database credentials in the secured runtime environment. Obtain faucet gas only from the [official faucet](https://www.qie.digital/faucet). If using the deployment's TESTUSD mock, explicitly set QIE_ALLOW_TEST_TOKEN=true; it has no monetary value. Mainnet never permits mocks.
2. **Validate before deployment:** `pnpm qie:validate-config --pre-deploy`. This testnet-only mode allows unset deployment addresses; configured addresses must still have code, token metadata must match and RPC must match. Resolve all failed preflight checks. Confirm the official explorer's manual source-verification flow or obtain QIE support instructions; no verification API has been assumed.
3. **Deploy:** finish the local suite first. Supply public DEPLOYER_ADDRESS, encrypted DEPLOYER_ACCOUNT name, QIE_TESTNET_RPC_URL and optional approved test STABLECOIN_ADDRESS. Leave STABLECOIN_ADDRESS blank only to create TEST ONLY Loop Dollar. Run `pnpm contracts:deploy:testnet` and operate the keystore locally. The wrapper and Solidity script refuse mainnet. Keep signing material outside the repository.
4. **Verify:** verify each contract in the official explorer, as the [official hackathon quickstart](https://hackathon.qie.digital/) directs. If QIE confirms Blockscout API compatibility, populate the existing verification adapter's public arguments and run `pnpm contracts:verify:testnet` per contract. Otherwise use the official manual workflow and record it. Do not guess an API URL or blindly set confirmation flags.
5. **Record:** copy Registry, Checkout, Rewards and token addresses and first deployment block into the evidence template and public configuration. Check constructor args, role owners, immutable wiring, approved token, chain and deployed bytecode against the reviewed source. Run `pnpm qie:validate-config` and `pnpm qie:smoke-test`; full mode requires all code and metadata gates, plus source-workflow confirmation. Record source links separately; configuration validation is not proof of verified source.
6. **Register merchant:** connect a test wallet, register business metadata and intended payout, verify the profile receipt. Publish no customer data.
7. **Fund campaign:** create an Open campaign with self-payment protection enabled, review dates/bps/cap, approve exact funding and deposit in a separate transaction. Confirm vault budget and zero initial reserved amount.
8. **Create invoice:** use an invoice with a small test-token amount and campaign ID. Use explicit test flag for exclusion tests; use an unflagged testnet invoice solely for the isolated testnet earning rehearsal. Neither belongs in real pilot traction. Share the QR URL.
9. **Customer payment:** use a second test wallet, check chain/token/current payout, approve exact amount, then separately pay. Record transaction and confirm direct payout and zero checkout custody.
10. **Reward earning:** compare receipt RewardEarned to configured bps, cap and budget. Exercise self-payment exclusion, disabled rewards, test invoices and unavailable QIE ID mode; payment succeeds but ineligible cases earn zero.
11. **Partner opt-in:** register a second merchant and join the partner network.
12. **Redeem:** redeem part of earned credits at that merchant; verify reserve-to-partner payout and lower budget/reserved balances.
13. **Close campaign:** pause/resume rehearsal first, then acknowledge permanent closure. Prove resume fails after closure and new payments earn no more rewards.
14. **Refund:** read on-chain budget and reserved, withdraw at most their difference to a reviewed test address. Verify event and balance deltas. Attempt an unauthorized/excess refund in simulation; it must fail. Redeem remaining credits after close.
15. **Inspect:** run migrations, start indexer and verify canonical checkpoint/head/lag in `/api/readiness`. Compare funding - redemption - withdrawal to budget, earned - redeemed to reserved, and gross/eligible/reward-earning/test/self metrics. Exercise replay only against a backed-up test environment following indexer-recovery.md.
16. **Evidence:** record public receipts, source links, screenshots, QA outcomes, commit SHA, known gaps and owner sign-off. Redact unrelated wallet/account details. Complete wallet-qa.md on real devices before making compatibility claims.

A failed check or missing official input is a release gate. No automated mainnet command exists. Testnet completion does not authorize mainnet; independent review, verified source, officially confirmed stablecoin identity and explicit human release approval remain required.

Before starting the web app, ensure apps/web/.env.local reads the selected testnet .env.local rather than the legacy local .env symlink. Use a secured local copy or replace that local symlink explicitly. Restart/rebuild after changing public configuration. The indexer and deployment wrappers load root .env.local first, with .env retained for legacy local workflows.
