# Five-minute evidence-led demo

State the commit, actual network and release state first. If no testnet deployment evidence exists, say "local Anvil rehearsal"; show the browser demo label if using simulation. Do not present testnet/mock amounts as real sales.

1. Open the existing warm LoopPay home and registered merchant. Explain direct wallet settlement and the funded loyalty reserve.
2. Show an Open campaign's percentage/cap and default self-payment protection, exact funding approval and funded budget. Contrast the visibly unavailable QIE ID mode without claiming identity integration is live.
3. Create a QR invoice, switch to a different test wallet, show eligibility, approve exact spend and pay. Open the confirmed receipt, token transfer and earned-credit event.
4. Redeem part at an opted-in second merchant. Show its payout, outstanding non-transferable credit and budget/reserved accounting.
5. Permanently close the issuer campaign, refund only unreserved budget, then redeem an already-earned remaining credit. Show excess withdrawal rejection.
6. Show analytics with separate gross, eligible, earning and excluded counts; explain that public addresses are not people and mock/testnet activity is excluded from traction.
7. Open readiness, wallet QA and release evidence. State remaining official inputs, external review and real-device checks. No mainnet or audit claim.

Keep public transaction hashes and explorer/source links ready. If RPC/indexer fails, show the real unavailable state and explain recovery; do not substitute synthetic results as live evidence.
